This VSCode extension for "On-The-Fly" refactoring detection while coding.

## Features

Refactorings featured:

- Extract Method
- Rename Variable
- Inline Variable
- Replace Magic Literal
- Decompose Conditional

## Extension Settings

This extension contributes the following settings:

* `Refactoring-Detection-Tool.triggerRefactoring`: Enable/disable this extension.
Or use the shortcut: windows: ctrl+shift+r
                     mac: cmd+shift+r
